# Content and inquiry backend

Strapi 5.57.0 uses PostgreSQL and the AWS S3 upload provider with a configurable S3-compatible endpoint. The VM Compose file supplies configuration, creates the public image bucket, and can seed demo content in development.

Models: Product, Project Case, Article, Certificate, FAQ, Site Setting, and Inquiry. Public models have draft/publish and localized text through Strapi 5's built-in i18n. The current frontend reads the default locale. Inquiry has no draft/publish, is not localized, and exposes no public CRUD routes. Strapi supplies its `createdAt` timestamp; `internalNotes` remains private.

Custom Content API routes:

- `GET /api/homepage`: explicit published product/FAQ/site-setting fields only; preserves the `{ products, faqs, settings }` contract, including FAQ `[question, answer]` pairs.
- `GET /api/products`, `/api/project-cases`, `/api/articles`, `/api/certificates`, `/api/faqs`: public published lists with `{ data, meta: { pagination } }` responses.
- `GET /api/products/:documentId`, `/api/project-cases/:documentId`, `/api/articles/:documentId`, `/api/certificates/:documentId`, `/api/faqs/:documentId`: published detail responses with `{ data, meta }`; missing or draft-only documents return 404. Use the Strapi 5 `documentId` from a list response.
- `GET /api/site-setting`: the published single type, with `{ data, meta }`; `data` is null if no published setting exists.
- `GET /api/health`: verifies the database connection.
- `POST /api/inquiries/submit`: its route policy requires `Authorization: Bearer STRAPI_SERVER_TOKEN` before trusting the forwarded visitor IP and enforcing five requests per minute. The service validates/normalizes approved fields, verifies Turnstile when enabled, and persists `followUpStatus: new`. Only a saved record returns `{ id: string, status: "received" }`.

Set `STRAPI_SERVER_TOKEN` directly in the environment. This is a shared service credential verified by the route policy, not a token created in Strapi's API Token UI. Leave both Turnstile keys absent to disable challenges; enabling verification requires `TURNSTILE_SITE_KEY` at Next and CMS runtime and CMS-only `TURNSTILE_SECRET_KEY`, with optional CMS `TURNSTILE_EXPECTED_HOSTNAME`. Incomplete CMS configuration fails closed. Proof uses `turnstileToken` and action `inquiry`; it is never persisted.

All public content reads accept an optional `locale`, for example `/api/homepage?locale=en` or `/api/products?locale=zh-Hans`. Omit it to use Strapi's configured default locale. Create and publish the translation in Content Manager first; a locale without published content returns an empty list or null. A malformed locale, a locale array/object, `*`, or `all` returns 400. These routes always query published content, including when the client supplies `status=draft` or `publicationState=preview`.

Lists accept `pagination[page]` and `pagination[pageSize]`, defaulting to page 1 and 25 rows; page size is capped at 100. Use `/api/products?pagination[page]=2&pagination[pageSize]=12`. Non-positive or malformed pagination returns 400. Lists sort by `sortOrder`, then `documentId`. Fields and media are selected by the server; arbitrary client `filters`, `fields`, `sort`, and `populate` are ignored. Responses exclude admin identities and storage provider metadata. No public create, update, or delete route is registered for these content types; no Public role write permissions are needed.

Use Node.js 24 LTS locally and in deployment. PostgreSQL may be configured by optional `DATABASE_URL` or the VM's existing `DATABASE_HOST`, `DATABASE_PORT`, `DATABASE_NAME`, `DATABASE_USERNAME`, and `DATABASE_PASSWORD` variables. A supplied URL takes precedence for connection credentials. Use `DATABASE_SSL` and `DATABASE_SSL_REJECT_UNAUTHORIZED` for SSL settings; a URL containing SSL parameters follows the PostgreSQL driver's URL precedence. The connection pool minimum is fixed at 0. `IS_PROXIED` defaults to true and `MAX_IPS_COUNT` to 1; place Strapi behind the trusted proxy configured by deployment. Remote transfer defaults to disabled; enable it explicitly with `STRAPI_REMOTE_TRANSFER_ENABLED=true` only when required. Keep all secrets in environment variables. Next.js consumes the Content API and never connects to PostgreSQL.

Create an administrator at `/admin`. Use Content Manager for editing/publishing public content and viewing/updating inquiries. Media Library uploads public website images; bind an uploaded image to a Product's `image` field. Project Case supports `slug`, localized `detail`, `image`, and `gallery` while retaining `imageUrl`; its slug is optional to preserve existing entries. Articles use localized `title`, `summary`, and `body` plus `coverImage`. Certificates use localized `title`, `description`, and `issuer` plus a public `document` upload. No articles, cases, or certificates are seeded. Publish only verified business content. Internal inquiry notes stay private.

Bootstrap provisions Operations and Sales admin roles once, without accounts, and preserves subsequent manual role edits. Operations manages the six public content types and public media; Sales reads inquiries and can update only `followUpStatus` and `internalNotes`. A human super administrator invites/assigns users. Do not combine these roles with broader roles if the boundary is required. Initial Operations grants cover the configured locales; adding a language requires a manual role locale-scope update. These are admin RBAC roles, not Content API login roles.

The raw `database/migrations` directory must ship with the CMS. Its bounded inquiry migration renames the old PostgreSQL `status` column to `follow_up_status`, preserving saved values and avoiding Strapi Content Manager's reserved `status` field. Back up the database before first deployment; ambiguous dual columns stop startup. Real database/admin/S3 acceptance remains a Linux VM step.

See [inquiry workflow](../../docs/operations/inquiry-workflow.md), the root README and `docs/operations/vm-development.md` for operation, startup and persistence checks. SMTP and notification delivery are not implemented in this slice.
