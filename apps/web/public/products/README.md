# Company brochure assets

These images were extracted from the company PDFs provided in the project chat:

- Container House.pdf: four expandable container house models and an exterior illustration.
- TSBD Capsul house-HGB .pdf: the D7 capsule model, an exterior render and an interior illustration.

See sources.json for the source page and crop for each file. Crops remove page headings and layout decoration without inventing a new product. White backgrounds are preserved; PDF soft masks are composited over white. Files are served locally as WebP. The original PDF files are not distributed in this repository.

The product specifications and English / Simplified Chinese copy are in packages/contracts/company-products.json. Read parameters from the basic specification tables where a floor plan differs. Illustrations are catalogue materials, not evidence of a delivered project.
