# Technical Documents 下载页

前台入口保持 `/resources/technical-documents?lang=en`，按房屋和电器设备分别显示下载列表。按钮通过网站的下载接口返回文件附件，PDF 等文件也会直接下载。

后台 **Content Manager → Single Types** 新增：

- **Housing Documents**：房屋文档。
- **Electrical Equipment Documents**：电器设备文档。

每个入口可设置分类标题 `title`、简介 `summary`，并在 `documents` 中反复添加文档。每份文档填写必填名称 `title`、可选说明 `description`，并上传或从媒体库选择必填文件 `file`。支持 PDF、Office、压缩包和图片等文件，实际类型及大小限制沿用媒体库。可以增加、删除、拖动排序文档。

本机验证时已在每个分类放入一份标注为下载测试的 TXT 文件，并分别发布英文、法语、阿拉伯语版本，便于直接预览和测试下载。这些样例不包含产品参数或认证信息，正式使用时请在对应语言中替换为审核后的文档；本机内容不会随代码自动导入线上数据库。

英文、法语和阿拉伯语分别编辑和发布；所需翻译可通过后台复制语言内容后修改。文件可复用同一媒体库文件。包含文档组件的这两个模型使用手动翻译，不接入现有的纯文本自动翻译流程。

保存草稿不会改变下载页。发布后，列表在约 30 秒缓存刷新后更新；下载按钮每次重新检查对应语言的已发布文档。删除某个文档并重新发布，或取消发布分类，会使该项下载接口不再提供文件。未发布或尚无文件时显示空列表提示。后台媒体库的原始公共地址仍遵循已有媒体存储访问方式。

下载链接采用媒体文件的稳定 `documentId`，不依赖每次发布都会改变的重复组件行编号。修改标题或说明后重新发布，同一文件的下载链接继续有效。

新增的两个 Single Types 和一个重复组件均为新增表，现有 Applications、产品、媒体和其他数据不迁移、不覆盖。CMS/Web 可分步升级；旧 CMS 缺少新接口时，下载页显示空列表。回退代码不需要删除新表。

新建 Operations 角色默认可编辑和发布这两类文档。已有账号的自定义权限保留；如果看不到入口或字段，由 Super Admin 在 **Settings → Administration Panel → Roles** 中授权这两项的所需语言、字段和发布权限。
