# 网站语言：英语、阿拉伯语与法语

前台提供 English（`?lang=en`，默认）、العربية（`?lang=ar`）和 Français（`?lang=fr`）。旧的中文链接永久跳转到对应英文页面，旧的中文偏好不再启用中文。后台中文操作界面和已有中文内容保留。

阿拉伯语页面初始 HTML 带有 `lang="ar" dir="ltr"`，沿用英文版的页面排列：Logo、导航、首页图片、产品侧栏、产品详情页、询盘弹窗的关闭按钮和表单字段均保持原位置，不镜像翻转。仅阿拉伯语文字使用从右到左的阅读方向，型号、尺寸、邮箱保留从左到右的顺序；输入框根据输入内容自动选择文字方向。阿拉伯语使用本地托管、遵循 OFL 许可的 Noto Sans Arabic 字体；英文和法语使用阿里巴巴普惠体。导航、产品目录、产品详情页、询盘和错误提示支持阿拉伯语。

## CMS 内容准备

三种语言均沿用现有页面布局。阿拉伯语区块中的文字沿原版的对齐边排列，保留文字的从右到左阅读顺序；居中标题继续居中。法语从左到右阅读，沿用阿里巴巴普惠体，支持重音字符。切换语言保留当前产品路径和首页锚点，浏览器记住所选语言。

正常网站只读取所选语言的已发布 CMS 内容，不会自动改用英文或演示资料。`SITE_PREVIEW_MODE=true` 和 `/preview` 的本地预览包含 113 款阿拉伯语、法语产品及各四条 FAQ。

部署新 CMS 代码后，在具备数据库和媒体配置的 CMS 环境中执行：

```sh
npm --workspace @modular/cms run backfill:arabic
npm --workspace @modular/cms run backfill:french
```

这会预览缺失、可创建、已有译文和源内容已变更的记录。确认清单后执行：

```sh
npm --workspace @modular/cms run backfill:arabic -- --apply
npm --workspace @modular/cms run backfill:french -- --apply
```

分别按需要运行命令。脚本添加 `ar` 或 `fr` 内容语言，并在同一产品文档下创建缺失的对应语言版本；图片、相册、附件及所有既有语言内容保留。已有目标语言草稿或已发布版本均跳过。被人工修改的英文内容及未发布产品也跳过，避免发布与实际产品不一致的译文。此类内容应由运营人员翻译、校对和发布。

若英文有电器设备产品，法语或阿拉伯语只有房屋产品，先检查对应语言是否缺少已发布的产品版本。可以仅补齐产品，不处理 FAQ 和网站设置：

```sh
npm --workspace @modular/cms run backfill:french -- --products-only
npm --workspace @modular/cms run backfill:arabic -- --products-only
```

核对预览后，在同一命令末尾添加 `--apply`，使用仓库已有译文补齐缺失版本。此工具用于一次性补全初始产品译文，不会持续同步后续英文修改；未配置自动翻译时，仍需分别编辑和发布三种语言。后台发布内容通常在前台约 30 秒缓存刷新后显示。

超级管理员需在 Operations 角色的内容权限中补选 `ar`、`fr`，包含读取、新增、编辑、发布以及相关字段；已有角色权限不会自动扩大。后台可继续使用中文操作。

已配置自动翻译时，发布将同步到英语、阿拉伯语、法语中除源语言之外的已配置语言；中文可保留作为后台编辑来源，不再作为自动翻译目标。自动翻译的权限校验和事务回滚继续生效。新增语言不会自动回填所有历史企业文章、项目案例和资质资料。

上线前复核各语言的产品术语，并分别验收三种语言的首页、两大产品类、详情、手机菜单及真实询盘保存。沿用仓库既有 ECS bundle 与 zd-compose 发布流程。
