# 业务人员编辑产品页

后台入口：本机开发环境 http://localhost:1337/admin → Content Manager → Product。

## 日常操作

1. 打开产品，先在右上角确认语言（English / Français / العربية）。字段标签为中文，填写的网站内容使用当前所选语言。
2. 按页面分区填写；技术参数、配置项、FAQ 点击“添加”逐条填写，可以上移、下移或删除。
3. 点 Save（保存）仅保存草稿；点 Publish（发布）才会对前台公开。前台存在约 30 秒的内容缓存。
4. 发布后打开对应产品页，核对文字、图片、参数和 FAQ。若服务器启用了自动翻译，发布仍沿用既有翻译流程。

| 后台分区 | 对应前台位置 |
| --- | --- |
| 产品名称、简介 | 页面标题、标题下方简介及产品概览 |
| 所属产品分类 | 房屋/电气设备下的具体产品列表 |
| 原有分类文字（兼容字段） | 正式页面优先使用“产品分类”中维护的名称；旧文案保留兼容 |
| 产品详细介绍 | Product overview |
| 技术参数 | Technical specifications；前五条用于 At a glance |
| 配置与可选项 | 产品概览列表、Configuration and options |
| 产品主图、相册 | 列表首图、详情页图片和缩略图 |
| 产品资料附件 | 产品资料下载链接 |
| 产品常见问题 | 详情页底部询盘表单左侧 FAQ |

FAQ 留空时显示网站默认的四条问题；填写后用本产品的问题替换。不完整的问答不展示。参数需填写名称与数值，名称不要含冒号。配置可直接填写一句话，不需要 JSON。

“所属产品分类”读取后台已发布分类，按房屋和电气设备分组；新分类要先发布，才可在产品中选择。分类增删、名称、排序及显示状态在 Collection Types → 产品分类中统一维护，见[产品分类操作说明](product-categories.md)。

网址标识、备用图片地址、内部来源放在最后的高级设置。已有产品的网址标识尽量保持不变。图片仍使用原有媒体库选择器，不会自动修改旧图片。

## 权限与兼容

保留既有产品正文和选项的数据格式；打开编辑页不会重写、迁移或发布产品。新增的产品 FAQ 独立存储，可按语言填写。不改动已有角色的人工授权。

若使用已存在的 Operations 等业务角色，管理员需到 Settings → Administration panel → Roles，在 Product 的读、创建、编辑权限中勾选新增的 `productFaqs` 字段，并保留需要的发布和媒体库权限。Super Admin 可直接使用；新建系统默认 Operations 角色会包含该字段。没有发布权限的账号只能保存草稿。
