## 后台维护

后台：`http://localhost:1337/admin` → Content Manager → Collection Types。

- 产品：Product（产品页面编辑），可修改名称、分类、简介、逐条参数、配置、主图、相册、FAQ 等。
- 分类：产品分类，维护 6 类的多语言名称和排序。
- 保存只更新草稿；发布后网站按现有约 30 秒的数据缓存同步。
- 本机自动翻译开关当前关闭，本次已提供三语初始内容；后续修改要分别维护各语言，或另行配置已有自动翻译流程。

回退时先保留本机现状，将备份恢复至独立测试数据库核对，再决定切换；完整数据库回退会影响备份后的其他本机修改，不能直接覆盖当前库。所有旧媒体均保留。

仓库根目录可执行以下命令；脚本会强制核对本机数据库及媒体服务地址，不能用于 ECS。

```powershell
# 只读审计
node apps/cms/scripts/replace-housing-catalogue.cjs --bundle output/zhuduo-housing-catalogue
# 数据、语言、图片关联及电器设备保留校验
node apps/cms/scripts/replace-housing-catalogue.cjs --bundle output/zhuduo-housing-catalogue --verify
# 本机替换，必须已存在完整备份；重复执行相同清单时不写入
node apps/cms/scripts/replace-housing-catalogue.cjs --bundle output/zhuduo-housing-catalogue --apply
```

导入先校验全部资源并上传，随后通过 Strapi 文档服务在数据库事务中更新分类、三语产品及发布状态，最后移除旧房屋内容。保留电器设备的校验失败会取消事务。已导入后若发现业务另行编辑，脚本会拒绝覆盖。
